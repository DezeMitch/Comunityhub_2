## Tell us about the project's reach and impact

I am building **CommunityHub**, an open-source, self-hostable community platform for gaming communities, developers, creators, and online organizations.

Most communities currently stitch together separate tools â€” forums, Discord bots, ticket systems, knowledge bases, application forms, event tools, and member portals. That creates fragmented member data, inconsistent permissions, and expensive or closed ecosystems. CommunityHub aims to replace that fragmented stack with one modular platform that communities can own and extend.

The project is MIT-licensed and designed to help communities of all sizes:

- manage members, roles, and permissions in one place
- run forums, tickets, docs, events, and applications together
- integrate deeply with Discord
- extend functionality through a plugin system and public REST API
- self-host without vendor lock-in

Because CommunityHub is open source, others can audit the code, contribute features, self-host privately, and build plugins for ecosystems such as FiveM, Minecraft, Rust, and other community platforms. My goal is to create a transparent, community-driven alternative that benefits thousands of communities worldwide over time.
